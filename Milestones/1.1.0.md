# 1.1.0

First maintenance release after 1.0.0. It collects the problems reported with 1.0.0 and fixes them: tables, scripts and workflows that behave differently from Cheat Engine, crashes and wrong results. No large new features; those wait for a later version.

An issue belongs here when it was found in 1.0.0 and is fixed for this release. The release goes out once the reported issues are fixed and confirmed. The issues are in the GitHub milestone "v1.1.0".

## Done when

- **Robust:** no open crash or data-loss issue in this milestone. `--table-roundtrip` over real Cheat Engine tables shows no loss except the items decided on. The full test suite passes, including suite `workspace` for the table-replace flows.
- **Performance:** first and next scan, Structure Dissect per frame, start-up time and idle CPU are measured once and are not worse than 1.0.0.
- **Resources:** memory, handles and threads stay level over an hour of use, with and without the in-process agent in the target.
- **Code:** changes stay small and are made where a fix needs them; no clean-up rewrite before the release.
- **Scope:** only small additions; new features wait for the next version.
