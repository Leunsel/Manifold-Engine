# The Lua API of Cheat Engine 7.5 as Manifold Engine documents it.
#
# The names, parameters, property types and the class tree follow Cheat Engine 7.5's
# Lua documentation, so scripts written for Cheat Engine find the same entries here.
# The descriptions are written for this project. Tools/gen_lua_docs.py turns this file
# into Source/Generated/LuaDocs.cpp.
#
#   class <Name> [: <Parent>]
#   function <name>(<params>)
#   method <Class>.<name>(<params>)
#   property <Class>.<name> [: <type, or the allowed values as 'a', 'b'>]
#
# The indented line under an entry is its description: plain ASCII, one or two
# sentences, never " - " (the documentation panel reads that as type and text).

function getCEVersion()
    Returns the Cheat Engine version this program reports, as a number.

function getCheatEngineFileVersion()
    Returns the complete program version: a raw integer, plus a table with fields major, minor, release, build.

function getOperatingSystem()
    Returns the operating system as an integer: 0 for Windows, 1 for Mac.

function darkMode()
    Returns true when Windows runs in dark mode.

function activateProtection()
    Applies a basic protection that keeps simple memory scanners from opening this process. Of limited use.

function enableDRM(altitude OPTIONAL, secondaryprocessid OPTIONAL)
    Enables kernel-mode protection that stops ordinary scanners from reading this process. A secondary process ID extends it to another process, such as the game. Both arguments are optional.

function fullAccess(address,size)
    Makes the memory block at the address, of the given size, both writable and executable.

function setMemoryProtection(address, size, {R:boolean; W: Boolean; X: Boolean})
    Applies the protection flags R, W and X, given as booleans in a table, to the address range. Some systems refuse to combine W and X.

function loadTable(filename, merge OPTIONAL)
    Loads a table file (.ct or .cetrainer). When merge is true, the existing table is kept and the file's contents are added.

function loadTable(stream ,merge OPTIONAL, ignoreluascriptdialog BOOLEAN)
    Reads table contents from a stream object. merge optionally keeps the existing table; ignoreluascriptdialog is an optional boolean.

function saveTable(filename, protect OPTIONAL, dontDeactivateDesignerForms OPTIONAL)
    Saves the current table to a file. With protect set to true and a .CETRAINER file name, the result is protected against normal reading.

function saveTable(stream, dontDeactivateDesignerForms OPTIONAL)
    Saves the current table into a stream object. The optional flag controls whether designer forms stay active.

function signTable(filename)
    Signs the given table file with this install's signature, if it has a valid one. A password prompt appears.

function copyMemory(sourceAddress: integer, size: integer, destinationAddress:integer SEMIOPTIONAL, Method:integer OPTIONAL)
    Copies size bytes from the source address to the destination address. The destination is optional and the method selects how the copy is done.

function compareMemory(address1: integer; address2: integer; size: integer; method: integer)
    Compares size bytes at two addresses, using the given method.

function readBytes(address,bytecount, ReturnAsTable)
    Returns the bytes found at the address, as separate values. With ReturnAsTable set to true, returns them as one table.

function writeBytes(address, x,x,x,x,...)
    Writes the listed byte values to the address, one after another.

function writeBytes(address, table)
    Writes the bytes of the given table to the address.

function readShortInteger(address)
    Reads one byte (8 bits) at the address and returns it as an integer. Also known as readByte.

function readSmallInteger(address)
    Reads two bytes (16 bits) at the address and returns an integer.

function readInteger(address)
    Reads four bytes (32 bits) at the address and returns an integer.

function readQword(address)
    Reads eight bytes (64 bits) at the address and returns an integer.

function readPointer(address)
    Reads a pointer-sized integer from the address: 64 bits for a 64-bit target, 32 bits for a 32-bit target.

function readFloat(address)
    Reads a single-precision float from the address.

function readDouble(address)
    Reads a double-precision float from the address.

function readString(address, maxlength, widechar OPTIONAL)
    Reads text from the address up to its 0 terminator or maxlength characters. Set widechar to true for UTF-16 text. Returns a string.

function writeShortInteger(address,value)
    Stores one byte (8 bits) at the address, reporting success as true. Also known as writeByte.

function writeSmallInteger(address,value)
    Stores two bytes (16 bits) at the address, reporting success as true.

function writeInteger(address,value)
    Stores four bytes (32 bits) at the address, reporting success as true.

function writeQword(address, value)
    Stores eight bytes (64 bits) at the address, reporting success as true.

function writePointer(address,value)
    Writes a pointer-sized integer to the address, sized to the target's pointer width.

function writeFloat(address,value)
    Writes a single-precision float to the address and returns true on success.

function writeDouble(address,value)
    Writes a double-precision float to the address and returns true on success.

function writeString(address,text, widechar OPTIONAL)
    Writes the text to the address and returns true on success. Set widechar to true to write it as UTF-16.

function readBytesLocal(address,bytecount, ReturnAsTable)
    Works like readBytes, but reads from this program's own memory.

function readSmallIntegerLocal(address)
    Reads two bytes (16 bits) at the address of this program's own memory and returns an integer.

function readIntegerLocal(address)
    Reads four bytes (32 bits) at the address of this program's own memory and returns an integer.

function readQwordLocal(address)
    Reads eight bytes (64 bits) at the address of this program's own memory and returns an integer.

function readPointerLocal(address)
    Reads a pointer-sized integer from the address in this program's own memory.

function readFloatLocal(address)
    Reads a single-precision float from the address in this program's own memory.

function readDoubleLocal(address)
    Reads a double-precision float from the address in this program's own memory.

function readStringLocal(address, maxlength, widechar OPTIONAL)
    Reads text from the address in this program's own memory, up to its terminator or maxlength. Set widechar to true for UTF-16.

function writeSmallIntegerLocal(address,value)
    Stores two bytes (16 bits) at the address of this program's own memory, reporting success as true.

function writeIntegerLocal(address,value)
    Stores four bytes (32 bits) at the address of this program's own memory, reporting success as true.

function writeQwordLocal(address,value)
    Stores eight bytes (64 bits) at the address of this program's own memory, reporting success as true.

function writePointerLocal(address,value)
    Writes a pointer-sized integer to the address in this program's own memory.

function writeFloatLocal(address,value)
    Writes a single-precision float to the address in this program's own memory and returns true on success.

function writeDoubleLocal(address,value)
    Writes a double-precision float to the address in this program's own memory and returns true on success.

function writeStringLocal(address,string, widechar OPTIONAL)
    Writes the string to the address in this program's own memory. Set widechar to true to write it as UTF-16.

function writeBytesLocal(address, x,x,x,x,...)
    Works like writeBytes, but writes the listed bytes into this program's own memory.

function writeBytesLocal(address, table, , count)
    Works like writeBytes, but writes the bytes of a table into this program's own memory. The optional count limits how many are written.

function signExtend(value,mostSignificantBit)
    Returns the value as a signed integer, treating the given bit as the sign bit: when it is set, the result is negative.

function wordToByteTable(number)
    Converts the number to a 2-byte table of byte values.

function dwordToByteTable(number)
    Converts the number to a 4-byte table of byte values.

function qwordToByteTable(number)
    Converts the number to an 8-byte table of byte values.

function floatToByteTable(number)
    Converts the number to a table of byte values holding its single-precision float form.

function doubleToByteTable(number)
    Converts the number to a table of byte values holding its double-precision float form.

function extendedToByteTable(number)
    Converts the number to a table of byte values holding its extended-precision float form.

function stringToByteTable(string)
    Converts the string to a table of byte values.

function wideStringToByteTable(string)
    Converts the string to UTF-16 and returns that as a table of byte values.

function byteTableToWord(table, OPTIONAL signed:boolean)
    Interprets a table of byte values as a 16-bit integer and returns it as a number. The optional flag selects signed.

function byteTableToDword(table, OPTIONAL signed:boolean)
    Interprets a table of byte values as a 32-bit integer and returns it as a number. The optional flag selects signed.

function byteTableToQword(table)
    Interprets a table of byte values as a 64-bit integer and returns it as a number.

function byteTableToFloat(table)
    Interprets a table of byte values as a single-precision float and returns it as a number.

function byteTableToDouble(table)
    Interprets a table of byte values as a double-precision float and returns it as a number.

function byteTableToExtended(table)
    Interprets a table of byte values as an extended-precision float and returns it as a double number.

function byteTableToString(table)
    Interprets a table of byte values as text and returns it as a string.

function byteTableToWideString(table)
    Interprets a table of byte values as UTF-16 text and returns it as a regular string.

function bOr(int1, int2)
    Returns the bitwise OR of the two integers.

function bXor(int1, int2)
    Returns the bitwise XOR of the two integers.

function bAnd(int1, int2)
    Returns the bitwise AND of the two integers.

function bShl(int, int2)
    Returns the first integer shifted left by the second integer's number of bits.

function bShr(int, int2)
    Returns the first integer shifted right by the second integer's number of bits.

function bNot(int)
    Returns the bitwise NOT of the integer.

function enumMemoryRegions()
    Returns an indexed table with one entry per memory region. Each entry holds Type, Protect, State, RegionSize, AllocationProtect, AllocationBase and BaseAddress.

function writeRegionToFile(filename, sourceaddress,size)
    Writes the memory region at the source address, of the given size, into a file. Returns how many bytes were written.

function readRegionFromFile(filename, destinationaddress)
    Reads the contents of a file into memory at the destination address.

function resetLuaState()
    Creates a fresh Lua state and makes it the active one. The previous state is not destroyed, so its memory stays allocated.

function getGlobalVariable(string)
    Returns a variable of the main Lua state by name. Only basic types work, which helps in threads that run in their own state.

function setGlobalVariable(string, something)
    Assigns a global variable by name in the Lua state that is the main one. Only basic types work.

function createRef(...)
    Stores the Lua value and returns an integer reference for getRef. Useful where only integers can be stored, such as Component.Tag.

function getRef(integer)
    Returns the value that the integer reference stands for.

function destroyRef(integer)
    Releases the integer reference.

function encodeFunction(function)
    Encodes a function as a string, which decodeFunction can later turn back into a function.

function decodeFunction(string)
    Rebuilds a function from its encoded string. Both steps must run on the same architecture, since 32-bit and 64-bit code do not mix.

function encodeFunctionEx(string,pathtodll OPTIONAL)
    Like encodeFunction, but encodes a script given as text. A Lua DLL can be named, but its bitness still has to match.

function getTranslationFolder()
    Returns the folder of the active translation files, or an empty string when no translation is in use.

function loadPOFile(path)
    Loads a .PO translation file from the given path.

function translate(string)
    Returns the translation of the string, or the string itself when none exists.

function translateID(translationid: string, originalstring: string OPTIONAL)
    Returns the translation for a translation ID. The optional second argument is the original string.

function ansiToUtf8(string)
    Converts a string from ANSI encoding to UTF-8.

function utf8ToAnsi(string)
    Converts a string from UTF-8 encoding to ANSI.

function enumModules(processid OPTIONAL)
    Returns a table of the modules loaded in a process. The process ID is optional and defaults to the opened process.

function md5memory(address, size)
    Returns the MD5 hash of the given memory block as a string.

function md5file(pathtofile)
    Returns the MD5 hash of the given file as a string.

function getFileVersion(pathtofile)
    Returns a file's 64-bit version number plus a table with the split parts: major, minor, release, build.

function getFileList(Path:string, searchMask:string OPTIONAL, SearchSubDirs: boolean OPTIONAL, DirAttrib: integer OPTIONAL)
    Returns a table listing the file names in the folder. Optional arguments: a search mask, whether to include subfolders, and an attribute filter.

function getDirectoryList(Path:string, SearchSubDirs: boolean OPTIONAL)
    Returns a table listing the directory names in the folder. Optionally includes subfolders.

function extractFileName(filepath)
    Returns the file name part of the path.

function extractFileExt(filepath)
    Returns the extension of the file in the path.

function extractFileNameWithoutExt(filepath)
    Returns the file name part of the path with its extension removed.

function extractFilePath(filepath)
    Returns the path with the file name cut off, leaving the folder.

function getTempFolder()
    Returns the path of the temp folder.

function fileExists(pathtofile)
    Returns true when a file exists at the path.

function deleteFile(pathtofile)
    Deletes the file and returns true when the file was there before and is gone now.

function enableWindowsSymbols()
    Downloads the Windows PDB symbol files and loads them. The first run takes a long time.

function getAddress(string, local OPTIONAL)
    Returns the address for a symbol name, such as a module name or an export. With local set to true, this program's own symbol table is queried.

function enableKernelSymbols()
    Turns on the kernel-mode symbols option of the memory viewer. Only exports are available unless enableWindowsSymbols was used.

function getAddressSafe(string, local OPTIONAL, shallow OPTIONAL)
    Looks up a symbol name and returns its address, or nil instead of raising an error when unknown. Takes optional local and shallow flags.

function getSymbolInfo(symbolname)
    Returns a table describing the symbol, with the fields modulename, searchkey, address and size.

function getModuleSize(modulename)
    Returns the size of the module in bytes. Use getAddress to get its base address.

function getRTTIClassName(address)
    Returns the class name of the structure at the address, based on RTTI, or nil when none is found.

function reinitializeSymbolhandler(waittilldone: BOOLEAN OPTIONAL, default=TRUE)
    Rebuilds the symbol handler, for example after new modules loaded. By default it waits until finished.

function reinitializeDotNetSymbolhandler(modulename OPTIONAL)
    Rebuilds just the .NET portion of the symbol list, for example after IL code got JIT compiled. A module name is optional.

function reinitializeSelfSymbolhandler(waittilldone: BOOLEAN OPTIONAL, default=TRUE)
    Rebuilds the symbol handler for this program's own process, for example after new modules loaded. By default it waits until finished.

function waitForSections()
    Blocks until the module sections have been enumerated.

function waitForExports()
    Blocks until every DLL export has been loaded.

function waitForDotNet()
    Blocks until every .NET symbol, DLL exports included, has been loaded.

function waitForPDB()
    Blocks until every PDB symbol, DLL exports and .NET symbols included, has been loaded.

function searchPDBWhileLoading(state: boolean)
    Sets whether symbol enumeration pauses to query the debug help handler for one particular symbol, which may be slow. Off by default.

function releaseDebugFiles()
    Stops the symbol loader from processing debug files and closes the ones it had open.

function errorOnLookupFailure(state)
    Sets whether a failed address lookup in string form raises an error. Default is true. Set to false, bad symbols and pointers give 0.

function waitforsymbols(state)
    Sets whether a symbol lookup waits until the symbol is loaded. Default is true.

function generateAPIHookScript(address:string, addresstojumpto:string, addresstogetnewcalladdress:string OPT, ext:string OPT, targetself:boolean OPT)
    Produces an auto assembler script that installs a hook on the address. Optional arguments give the source of the new call address, an extension, and whether to target this program.

function assemble(line, address OPTIONAL, assemblePreference OPTIONAL, skipRangeCheck OPTIONAL)
    Assembles a single line and returns the generated machine code as a byte table. Optional arguments: address, preference, skipRangeCheck.

function autoAssemble(text, targetself OPTIONAL, disableInfo OPTIONAL)
    Executes the auto assembler on the script text. On success it returns true plus a table for disabling later. targetself assembles into this program. disableInfo may be passed.

function autoAssemble(text, disableInfo OPTIONAL)
    Runs the auto assembler on the script text, using disableInfo from an earlier run to disable it.

function autoAssembleCheck(text, enable, targetself)
    Checks the script's syntax. Returns true when fine, or false and an error message.

function compile(text, address OPTIONAL, targetself OPTIONAL)
    Compiles C code. Returns a table of symbol addresses on success, or nil plus an error message.

function compile({indexedtable containing scripts}, address OPTIONAL, targetself OPTIONAL)
    Compiles several C scripts, given as an indexed table, together into one unit.

function compileFiles({filelist}, address OPTIONAL, targetself OPTIONAL)
    Compiles C code from a list of files, given as an indexed table.

function compileTCCLib()
    Compiles the TCC support library functions that some C code needs internally.

function addCIncludePath(path)
    Adds a folder to the default include paths used by compile.

function removeCIncludePath(path)
    Removes an include path that addCIncludePath added earlier.

function compileCS(text, {references}, coreAssembly OPTIONAL)
    Compiles C# source and returns the name of the generated file, deleted when the program closes. references lists the assemblies the code may use.

function dotNetExecuteClassMethod(pathtodll, namespace, classname, methodname, parameters: string)
    Calls a public static int method taking a string in a .NET class from the DLL, inside this program, and returns the integer. For the target process, see injectDotNetDLL.

function registerEXETrainerFeature(FeatureName:String, function():table)
    Adds a feature to the generator for exe trainers. Whenever a trainer is built, your function runs and must return a table holding PathToFile and RelativePath.

function unregisterEXETrainerFeature(id)
    Removes an EXE trainer feature registered earlier, by its ID.

function registerAutoAssemblerCommand(command, function(parameters, syntaxcheckonly))
    Makes a new command available in auto assembler scripts. Your function gets the parameters and a syntax check flag, and the command becomes whatever string it returns.

function unregisterAutoAssemblerCommand(command)
    Removes an auto assembler command registered earlier.

function registerLuaFunctionHighlight(functionname)
    Makes the Lua syntax highlighter show the name as a function keyword.

function unregisterLuaFunctionHighlight(functionname)
    Stops the Lua syntax highlighter from showing the name as a function keyword.

    Shows a message box with the given title, text, icon type and buttons.

    Displays an informational dialog containing the text.

function sleep(milliseconds)
    Pauses the script for the given number of milliseconds, where 1000 is one second.

function getProcesslist(Strings)
    Fills a Strings object with the system's processes, one line per process in the format %x-name, using the ID in hexadecimal.

    Returns a table of the system's processes, mapping each process ID to its name.

function getWindowlist(Strings)
    Fills a Strings object with the system's top-level windows, one line per window in the format %x-caption.

function getWindowlist()
    Returns a table of the system's top-level windows, shaped {pid,{id,caption}}.

function getThreadlist(List)
    Puts the threads of the opened process into a List object, each entry formatted as %x.

function getHandleList(filter OPTIONAL)
    Returns a table of system handles. Filter 0 is everything, 1 handles of the target, 2 handles to the target, 3 handles to this program. Entries have fields such as ProcessID and ObjectTypeIndex.

function closeRemoteHandle(handle, processid OPTIONAL)
    Closes a handle that belongs to another process. The process ID is optional.

function duplicateHandle(handle)
    Duplicates a handle of this program into the target process. The target still has to be told about it, for example in an injected DLL's data.

function duplicateHandle(handle, Mode (0/1))
    Duplicates a handle. Mode 0 behaves like the single-argument form. Mode 1 copies the target process's handle into this program.

function duplicateHandle(handle, fromPID, toPID)
    Copies a handle from the first given process to the second one.

function getOpenedProcessID()
    Returns the ID of the opened process, or 0 when none is open.

method VirtualStringTree.endUpdate()
    Ends a batch of changes and redraws the tree.

method VirtualStringTree.addChild(parent)
    Adds a child node below the given parent and returns it. A node is an opaque object that only the tree itself can use.

method VirtualStringTree.addToSelection(node)
    Adds the node to the selection.

method VirtualStringTree.removeFromSelection(node)
    Takes the node out of the selection.

method VirtualStringTree.getRootNode()
    Returns the root node of the tree.

method VirtualStringTree.absoluteIndex(node)
    Returns the node's absolute index as an integer.

method VirtualStringTree.nodeSelected(node)
    Returns true when the node is selected.

method VirtualStringTree.nodeChecked(node)
    Returns true when the node is checked.

method VirtualStringTree.enumSelectedNodes()
    Returns an indexed table with the selected nodes.

method VirtualStringTree.enumCheckedNodes()
    Returns an indexed table with the checked nodes.

method VirtualStringTree.enumChildren(node)
    Returns an indexed table with the child nodes of the node.

method VirtualStringTree.deleteNode(node)
    Removes the given node from the tree.

method VirtualStringTree.deleteSelectedNodes()
    Removes every node that is currently selected.

method VirtualStringTree.getNodeData(node)
    Returns the data stored in the node as a byte table.

method VirtualStringTree.setNodeData(node, bytetable)
    Stores a byte table as the node's data.

method VirtualStringTree.getNodeDataAsInteger(node)
    Returns the node data read as one integer.

method VirtualStringTree.setNodeDataAsInteger(node, integer)
    Stores the given integer as the data of the node.

method VirtualStringTree.getNodeDataPointer(node)
    Returns the address of the node data as an integer, for use with the local read and write functions instead of a byte table. Useful for large data.

method VirtualStringTree.getNodeParent(node)
    Returns the node's parent, or nil when it has none.

method VirtualStringTree.getFirstChild(node)
    Returns the node's first child.

method VirtualStringTree.getNextSibling(node)
    Returns the sibling that follows the node.

function connectToCEServer(hostname,port)
    Connects to a ceserver on the given port of the given host. Afterwards most operations, such as the process list and memory access, are handled by it.

function isConnectedToCEServer()
    Returns true when a ceserver connection is active.

function getCEServerPath()
    Returns the path of ceserver on the target, as a string.

function split(character)
    Splits the string at each occurrence of the character and returns a table of the parts.

function endsWith('string')
    Returns true when the string finishes with the given text.

function startsWith('string')
    Returns true when the string begins with the given text.
