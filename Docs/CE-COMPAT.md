# Cheat Engine API coverage

Generated by `Manifold-Engine.Tests.exe --ce-compat-markdown`; the tests compare this file with the program.

Manifold Engine provides the global functions of Cheat Engine 7.5's Lua documentation (`celua.txt`). The functions below are the exceptions: some exist but have no effect, the others are not available. [LUA-API.md](LUA-API.md) describes the functions that work. The documentation panel of the Lua engine window shows the same notes.

## Not available

A call does nothing and returns nil, or the value named after the function. The first call of each function in a session writes a warning to the Lua output with the script and line; the marked partners of `register` functions stay silent. These names are not stored in the global table, so `rawget(_G, name)` stays nil and a script that checks for a function first still takes its own way.

### Compilers

Manifold Engine has no built-in C or C# compiler.

`addCIncludePath`, `compile`, `compileCS`, `compileFiles`, `compileTCCLib` (false), `removeCIncludePath` (silent)

### .NET

Manifold Engine reads .NET games from outside (the Mono / .NET window, Class:Method and Class:StaticField addresses, Structure Dissect) but has no data collector object and does not inject .NET code.

`dotNetExecuteClassMethod`, `getDotNetDataCollector`, `injectDotNetDLL`

### ceserver

Manifold Engine does not connect to ceserver.

`connectToCEServer` (false), `getCEServerPath`

### Databases

Manifold Engine has no SQLite or ODBC classes.

`createODBCConnection`, `createSQLite3Connection`, `createSQLQuery`, `createSQLTransaction`, `setSQLiteLibraryName`

### XML documents

The XML document classes are not built in.

`createXMLDocument`, `createXMLDocumentFromFile`, `createXMLDocumentFromStream`

### Calls into the target

Reusable call stubs and the remote executor are not built in; executeCodeEx and executeMethod make the call directly.

`createExecuteCodeExStub`, `createExecuteMethodStub`, `createRemoteExecutor`

### Shared sections

Sections are not mapped into the target yet; allocateSharedMemoryLocal works inside Manifold Engine.

`allocateSharedMemory`, `createSection`, `mapViewOfSection`, `unMapViewOfSection` (false)

### Pipes

Lua pipes and the Lua server are not built in.

`connectToPipe`, `createPipe`, `openLuaServer`

### Callbacks without a hook point

Manifold Engine has no hook point for this callback yet, so it is never called.

`onAPIPointerChange`, `onAutoGuess`, `registerAddressLookupCallback` (an id), `registerAssembler` (an id), `registerAutoAssemblerPrologue` (an id), `registerBinUtil`, `registerEXETrainerFeature` (an id), `registerGlobalDisassembleOverride` (an id), `registerGlobalStructureListUpdateNotification` (an id), `registerStructureAndElementListCallback` (an id), `unregisterAddressLookupCallback` (silent), `unregisterAssembler` (silent), `unregisterAutoAssemblerPrologue` (silent), `unregisterEXETrainerFeature` (silent), `unregisterGlobalDisassembleOverride` (silent), `unregisterGlobalStructureListUpdateNotification` (silent), `unregisterStructureAndElementListCallback` (silent)

### Window hooks

Window procedure hooks are not built in.

`hookWndProc` (false), `unhookWndProc` (silent)

### Missing windows

This Cheat Engine window does not exist in Manifold Engine.

`getCodeFilter`, `getDissectCode`, `getHotkeyHandlerThread`, `getUltimap2`

### Screen drawing

Drawing on the screen is not built in.

`getScreenCanvas`

### Files as a process

Files cannot be opened as a process.

`getOpenedFileSize`, `openFileAsProcess` (false), `saveOpenedFile` (false)

### Plugins

Cheat Engine plugins cannot be loaded.

`loadPlugin`

### Encoded functions

Cheat Engine encodes Lua 5.3 bytecode, and Manifold Engine runs Lua 5.4.

`decodeFunction`, `encodeFunction`, `encodeFunctionEx`

### Form files

Form files (.FRM) cannot be read yet.

`createFormFromFile`, `createFormFromStream`

### Direct3D hook

The Direct3D overlay hook is not built in.

`createD3DHook`

### Handles

The handle list and handle duplication are not built in yet.

`closeRemoteHandle` (false), `duplicateHandle`, `getHandleList` (an empty table)

### Script generators

The Lua script generators are not built in yet; the Template menu of the Auto Assembler window writes the same scripts.

`addSnapshotAsComment`, `generateAOBInjectionScript`, `generateAPIHookScript`, `generateCodeInjectionScript`, `generateFullInjectionScript`

### Self-protection

Manifold Engine does not hide or protect its own process.

`activateProtection`, `enableDRM` (false)

### Lua state

Manifold Engine runs one Lua state for the whole session.

`resetLuaState`

### Debugger

The debugger does not support this yet.

`debug_addThreadToNoBreakList`, `debug_getXMMPointer`, `debug_removeThreadFromNoBreakList` (silent), `debug_setBreakpointForThread` (false)

### Fonts

Script windows draw with Manifold Engine's fonts.

`loadFontFromStream`, `unloadLoadedFont` (silent)

### Signatures

Manifold Engine does not sign tables.

`signTable` (false)

### Pointer size

The pointer size follows the opened process.

`setPointerSize`

### API pointers

Manifold Engine does not redirect its Windows API calls.

`setAPIPointer`

### Structure windows

Structure windows and their selection cannot be scripted yet.

`enumStructureForms` (an empty table), `getSelectedStructElement`

### PDB structures

Structures are not created from PDB types yet.

`createStructureFromName`

### Main scan

The main window's scan cannot be scripted yet; createMemScan gives a scan of your own.

`getCurrentMemscan`

### RIP-relative scanner

The RIP-relative scanner is not built in yet.

`createRipRelativeScanner`

### Symbol loader

The symbol loader cannot be stopped from Lua yet.

`releaseDebugFiles`
