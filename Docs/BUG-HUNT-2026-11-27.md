# Bug Hunt 2026-11-27

Base: `df02c29`. The hunt covered 12 areas and focused on the 33 commits since the previous hunt (`02fb034..`), which had not been reviewed yet.

Method:
- A suspected bug was treated as a bug only once a test showed it failing on the old code.
- Each fix is the smallest change that makes that test pass, with one commit per bug.
- Every fix was reviewed independently for new bugs in the fix itself. Problems found there were handled the same way.
- What could not be shown with a test is not fixed. It is listed below with a way to show it.
- What needs a design decision is not fixed. It is listed below with the smallest fix and the alternatives.

Evidence:
- **observed**: seen in a test run
- **read**: checked in the code
- **assumed**: neither seen nor checked
