# Keyboard shortcuts

Generated by `Manifold-Engine.Tests.exe --shortcuts-markdown` from `Source/App/Commands.cpp`; the core tests compare this file with the table.

Every shortcut belongs to a window or pane. Keys of the focused window win over the ones that work everywhere, so `Ctrl+S` saves the script in an Auto Assembler window and the cheat table elsewhere. Shortcuts marked **CE** are the ones Cheat Engine 7.5 uses for the same feature; the others are Manifold Engine's own. Keys without Ctrl or Alt do nothing while a text field has the focus. In the app, **Help > Keyboard Shortcuts** (`F1`) shows the same list with a search.

This file lists the defaults. **Settings > Keyboard** changes any of them: click the keys and press new ones, right-click to remove them. Changed keys are stored in `configs\Manifold-Engine.ini` under `[Shortcuts]` as `Key.<Command>=Ctrl+Shift+O` (a second shortcut after `;`, `none` for no keys), using the command names below.
